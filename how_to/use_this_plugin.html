Use the PLD logbooks¶

Short guides for the everyday tasks. For a complete walk-through of a run, see the tutorial. For every field and unit, see the reference.

Save to update

Calculated and copied values (sample IDs, 1st window transmission, target numbers, copied recipe steps, ...) are updated when the entry is saved, and the checks run at the same time. Messages appear after saving.

Manage the target database¶

Every physical target is one PLD Target entry.

  • Add a target: create a PLD Target entry with material, manufacturer and purchase date (optionally diameter, thickness, purity).
  • Naming: the entry is named after the name field, or after the material if the name is empty. Do not put the target number in the name: target positions change, and the number is entered per run in the logbook.
  • Two targets of the same material: give them different names, e.g. Fe2O3 (Praxair 2024) and Fe2O3 (Pi-Kem 2025), so you can tell them apart in the drop-down.

Start a logbook¶

Create an SA-PLD Logbook or LA-PLD Logbook. Pick the logbook of the system you ran on: it decides which carriers, step types and scan options are offered, and the PVD system field is set by it.

Fill in name, date (defaults to the first save), base pressure (mbar) and substrate carrier. For LA-PLD, also set particle reduction plate.

Record the laser calibration¶

Open laser details and enter the energy before and after the chamber (mJ). Transmission of the 2nd window is pre-filled with 92 %.

On save, the 1st window transmission is calculated as T1 = E_after / (E_before × T2):

You did Result on save
Entered both energies T1 is calculated (and recalculated on every save).
Typed your own T1, manual not ticked Your value is replaced by the calculated one.
Typed your own T1 and ticked manual Your value is kept.
Ticked manual but left T1 empty T1 is calculated.
Energy before chamber is 0 or an energy is missing T1 is not calculated (a warning is given for 0).

Select the targets of a run¶

Add one targets entry per target in the system: pick the PLD Target and enter its target number for this run. Material, manufacturer and purchase date are copied in on save so you can check your choice.

Checks: selecting the same target twice is an error; using a target number twice is a warning.

Create substrates¶

Add one substrates entry per substrate, with sample name, run number, sample number, size, material and comments, and save. Then:

  • sample user ID becomes <system>_<date>_<run>_<sample number> (date as YYYY-MM-DD, from the logbook date). It is only filled in once system, date, run number and sample number are all known.
  • sample UUID is generated once and never changes.
  • a PLD Substrate entry is created in the same upload (file <sample user ID>.archive.json) and linked in substrate.

Two substrates with the same sample user ID give a warning.

The substrate entry is created once

After the PLD Substrate entry exists, changes to the substrate in the logbook are not copied to it. Correct the PLD Substrate entry itself. Clearing the substrate field and saving links the existing entry again (found by its file name) without changing it. To have it created anew from the logbook, delete the PLD Substrate entry first, then clear the field and save.

To use a substrate that already exists, e.g. from an earlier run, skip substrates and pick the PLD Substrate directly in the deposition step (or in load recipe).

Add process steps¶

Add steps under steps in the order they were done. Only the steps of the logbook's own system are offered: pre-ablation, heating, pulsed laser deposition and cool-down. There is deliberately no sputter step in the PLD logbooks. Add a step type as often as you need; for a multilayer just add another deposition step.

Background gases (every step)¶

Add one background gases entry per gas that was on:

Field Meaning
gas Ar, O2 or N2
set flow flow set on the controller (sccm)
read-out flow flow measured / read out (sccm)
valve position valve position on the controller (%)
valve position fixed ticked if the valve was kept at a fixed position

Target of a pre-ablation or deposition step¶

Pick the target in target. The target number is taken from the target details on save, so the step always shows the current number. If only one target is selected in the logbook, empty step targets are filled in automatically. A step target that is not selected in the target details gives a warning.

Laser settings¶

The laser sub-section of pre-ablation and deposition steps holds laser mode, laser voltage (kV), magnification, mask size, spot size (mm²), fluence (J/cm²), energy (mJ), attenuator position (%), frequency (Hz) and number of pulses.

Heater stage¶

Deposition steps have a heater stage position with x, y, z (mm), tilt and spin (degrees).

  • SA-PLD: tick substrate stage scan if the stage scanned. On save a cartesian scan sub-section is added for x/y offset (mm), scan rate (mm/s) and rotation rate (rpm). Scan values while the box is unticked give a warning.

  • LA-PLD: choose heater scan type: Polar scan (default) or Cartesian scan. On save the matching sub-section is added:

    Polar scan Unit
    radius start mm
    radius stop mm
    pulse spacing mm
    max laser frequency Hz
    number of scans –

    Values in the scan type that is not selected are ignored, with a warning.

Target stage¶

Pre-ablation and deposition steps have a target stage sub-section: start x/y position, x/y offset and scan area (mm).

Record in-situ measurements¶

In-situ techniques are a separate part of the logbook (in situ techniques), not part of a step. For measurements that do not belong to a new run, e.g. an older sample that is post-processed, create a stand-alone PLD In-situ Techniques entry. Its sample (a PLD Substrate) and process (a logbook) fields are optional.

Add one sub-section per technique (more than one per technique is allowed, e.g. one RHEED entry per capture):

Technique Software Fields
RHEED KSA 400 pattern capture: native .img and exported .png; ROI intensity map: native .kdt and exported .txt
MIC EZ-Curve native .ezc and exported .csv
LA-EDS RSX1000 (later RaySpec RSX2000) .sp0 file, energy offset E0 (eV), energy per channel (eV), number of channels
SE, OES, SHG – one data file each

Native files can only be reopened in the instrument software. Upload them anyway: they are the raw data. The exported files can be opened elsewhere.

LA-EDS spectrum¶

The .sp0 file has no energy axis; it is rebuilt as E = E0 + channel number × energy per channel (channels counted from 0) and plotted as intensity versus energy.

Not yet automatic

The .sp0 file is not read yet: the location of E0 in the file still has to be confirmed with an example file. Until then the spectrum (intensity per channel) can only be added via an archive file, together with E0 and the energy per channel.

Write logbooks as archive files¶

Instead of using the form, you can upload YAML or JSON archive files; see tests/data/example_sa_pld.archive.yaml and tests/data/example_la_pld.archive.yaml.

  • Use m_def: differ_pld4e_schemas.schema_packages.schema_package.SAPLDLogbook (or LAPLDLogbook, PLDTarget, PLDSubstrate, InSituTechniquesEntry). Steps need their own m_def, e.g. ...schema_package.SAPLDDepositionStep.
  • Numbers are in SI units in archive files, whatever the form shows: Pa (not mbar), J (not mJ), m (not mm), K (not °C), m² for spot size, J/m² for fluence. For example 1e-8 mbar is 1.0e-6, 500 mJ is 0.5 and 700 °C is 973.15.
  • Reference an entry in the same upload by file name: '../upload/archive/mainfile/<file name>#data'.

Messages after saving¶

Message Level What to do
Target ... is selected more than once. error Remove the duplicate target.
Target number ... is used twice. warning Correct the target numbers.
Substrate ... is defined twice. warning Two substrates share run and sample number; correct one.
Step ... uses a target that is not selected in the target details. warning Add the target to the target details or change the step.
Laser energy before chamber is 0, cannot compute T1. warning Correct the energy.
Scan parameters are given but substrate stage scan is off. warning Tick the scan or remove the scan values (SA-PLD).
Cartesian/Polar scan parameters are ignored for a ... scan. warning Check the heater scan type (LA-PLD).
Select a recipe before applying it. error Pick a recipe in load recipe.
The recipe is from ..., not from .... error Use a recipe of the same system.
LA-EDS number of channels does not match the intensity. warning Check the number of channels.
